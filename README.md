# Лаба 1 — Локальный Lakehouse (MinIO → Lakekeeper → Trino)

Поднимаем локальный **Lakehouse** из трёх Docker-контейнеров: **MinIO** (S3-хранилище) → **Lakekeeper** (Iceberg REST Catalog) → **Trino** (SQL-движок). Затем поверх него строим **медальон** (Bronze → Silver → Gold).

## Что внутри

| Файл / папка | Что это |
|---|---|
| `гайд-лейкхаус.md` | гайд 1: поднять стек MinIO → Lakekeeper → Trino (macOS/Linux) |
| `гайд-лейкхаус-win.md` | гайд 1 для Windows |
| `гайд-лейкхаус.pdf` | PDF-версия гайда 1 |
| `гайд-2-медальон.md` | гайд 2: медальон Bronze → Silver → Gold |
| `catalog/` | конфиги каталогов Trino и запрос на создание warehouse в Lakekeeper |

## Порядок работы

1. **Гайд 1** (`гайд-лейкхаус.md`) — поднять и проверить стек MinIO → Lakekeeper → Trino.
2. **Гайд 2** (`гайд-2-медальон.md`) — построить три слоя медальона.

## Что сдаёшь

Ответы на проверочные вопросы в конце каждого гайда (что стек работает, слои построены и наполнены).
